# Woordenlijst

| Term | Betekenis |
|---|---|
| Access-token | Kortlevend token dat toegang geeft tot één API of resource |
| AD CS | Active Directory Certificate Services: de certificaatdienst van Windows Server |
| AiTM | Adversary-in-the-Middle: een proxy tussen gebruiker en aanmeldpagina die de sessie onderschept |
| BrowserCore | Onderdeel waarmee browsers op een Entra-joined toestel SSO krijgen via de PRT |
| CBA | Certificate-based authentication: aanmelden met een X.509-certificaat |
| Conditional Access | Policies in Entra ID die voorwaarden stellen aan een aanmelding |
| Domain binding | Een passkey tekent alleen voor het domein waarvoor ze is aangemaakt |
| ESC1 | Misconfiguratie in AD CS waarbij de aanvrager zelf de naam op het certificaat kiest |
| FIDO2 / WebAuthn | Standaarden voor aanmelden met een domeingebonden sleutelpaar |
| MFA | Multifactorauthenticatie |
| OIDC | OpenID Connect: authenticatielaag bovenop OAuth 2.0 |
| Passkey | FIDO2-sleutelpaar waarmee je zonder wachtwoord aanmeldt |
| PRT | Primary Refresh Token: toestelgebonden token dat SSO geeft naar alle Entra-applicaties |
| Proximity check | Controle via Bluetooth dat telefoon en pc fysiek dicht bij elkaar zijn |
| Refresh-token | Langlevend token waarmee nieuwe access-tokens worden opgehaald |
| Smart lockout | Mechanisme in Entra ID dat een account tijdelijk vergrendelt na foute wachtwoorden |
| Token Protection | Conditional Access-controle die eist dat een token aan een toestel gebonden is |
| TPM | Trusted Platform Module: chip die sleutels bewaart en niet vrijgeeft |
| WHFB | Windows Hello for Business: aanmelden met PIN of biometrie en een sleutel in de TPM |
