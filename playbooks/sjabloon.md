# Sjabloon

Kopieer deze pagina voor een nieuw playbook en vul elke kop in.

```
---
title: "PB-xx Titel"
nav_order: xx
parent: "Playbooks"
---

# PB-xx Titel

| | |
|---|---|
| **Pad** | |
| **Doel** | |
| **Tooling** | naam en versie |
| **Waar** | welke VM of welk toestel |
| **Status** | Getest / Analyse / Aan te vullen |

## Startcondities
Welke policies staan aan, welk account, welke MFA-methode is geregistreerd.

## Uitvoering
Genummerde stappen met de exacte commando's.

## Resultaat
Gelukt of mislukt, met de letterlijke uitvoer of foutcode.

## Waarom
De verklaring. Zeg het erbij als die niet geverifieerd is.

## Wat niet lukte
Waar liep je vast, en wat zou theoretisch toch moeten werken?

## Bewijs
Screenshots en de bestandsnaam van de schermopname.
```
